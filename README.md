# aQiten

An independent lattice polynomial-commitment framework: **zero-knowledge**, with
a **quantum-random-oracle** security argument, building on the ideas of the
Akita scheme (Dao et al., IACR ePrint 2026/1983) but written as its own
framework. Not a fork.

Status: **charter stage.** No cryptographic code exists yet. Nothing here may be
used to protect secrets.

* `CHARTER.md` – goals, security games G1–G3, scope, rules of work.
* `docs/P0_PLAN.md` – the first work package (literature and paper audit).
* `spec/` – specifications and proofs (LaTeX) precede code.
